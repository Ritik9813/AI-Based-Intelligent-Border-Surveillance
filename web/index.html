How the agents are controlled

  1. Orchestrator is the only route between agents and checks every output.
  2. Tool allow-list: each agent may use only its own tools.
  3. Human approval: High and Critical alerts must be acknowledged before a response can be dispatched.
  4. Corroboration and minimum confidence hold back weak detections.
  5. Escalation: a Critical alert left unacknowledged for 25 s goes to the commander.
  6. Audit log records every decision; operator actions become training labels.
  7. Fail-safe: if an agent fails, raw sensor alarms are used.
